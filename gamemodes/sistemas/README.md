# Sistemas de GZRP

Directorio destino para sistemas funcionales. La clasificación final se hará tras rastrear inclusiones y dependencias del código original.

Carpetas objetivo iniciales:
- `cuentas/`
- `inventario/`
- `vehiculos/`
- `casas/`
- `negocios/`
- `facciones/`
- `trabajos/`
- `economia/`
- `administracion/`
- `anticheat/`
- `interfaz/`
- `comunicaciones/`

No se debe asumir que estos nombres corresponden uno a uno con archivos existentes. Cada migración conservará la lógica y tendrá revisión de diff y compilación.
